# Accessibility

Target: WCAG 2.2 AA. Two layers check it.

## Automated (every PR)

`grammar-app/src/__tests__/a11y.test.tsx` runs axe-core (`src/test/axe.ts`) over every
page and dialog in jsdom, and asserts the keyboard behaviour axe can't see: skip link,
level switcher state, lesson navigation landmark, Reading tabs, keyboard-openable library
stories. A new page or dialog gets a case there.

jsdom does no layout, so the gate **cannot** check colour contrast, focus visibility,
reflow, or what a screen reader actually announces. Those are the manual pass below.

Known exemption: `aria-required-children` on the search page (see
`docs/refactor/FINDINGS.md`, "Accessibility").

## Manual pass (before a release, or after a UI change the gate can't see)

Run `npm run build && npm run preview`, open `/Nihongo/n5/grammar/1`.

Keyboard only (no mouse):

- [ ] First Tab shows **Skip to content**; Enter moves focus past the header.
- [ ] Every control shows a visible focus ring — indigo on light surfaces, white on the
      indigo header.
- [ ] Level pills, section tabs, header search, AI settings, English toggle reachable in order.
- [ ] Lesson sidebar: Tab through lessons; Enter opens one; the active lesson is announced
      as current.
- [ ] Grammar card → detail dialog: focus moves in, Tab stays inside, Escape closes, focus
      returns to the card that opened it. Same for AI settings and a library story.
- [ ] Reading: ←/→ and Home/End switch Practice Studio / Story Library; Tab leaves the
      tablist into the panel.
- [ ] Story Library: a story's title opens its preview with Enter; delete and "Open" buttons
      are reachable.
- [ ] Search: type in the header box, ↑/↓ move through results, Enter opens one.

Screen reader (VoiceOver or NVDA), spot-check:

- [ ] Landmarks list: banner, "Sections" nav, "N5 lessons" nav, main, contentinfo.
- [ ] Dialogs announce their title; icon-only buttons announce a name ("Close",
      "Delete story …").
- [ ] Reading tabs announce "tab, 1 of 2, selected".

Visual:

- [ ] Contrast — DevTools or a checker on body text, helper text, badges and the header.
      Known shortfalls are listed in FINDINGS.
- [ ] 200% zoom and a 320 px wide window: no horizontal scroll, nothing clipped.
- [ ] `prefers-reduced-motion`: nothing essential depends on animation.

Record anything that fails in `docs/refactor/FINDINGS.md`.
